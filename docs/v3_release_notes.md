# v3.0-rc

## Highlights

- Full backend covering knowledge, retrieval, safety, memory,
  skills, projects, learning paths, context building, audit, evaluation,
  reporting, reasoning templates, authorized workflow, task routing,
  benchmark, and agent reports.
- 32 Markdown knowledge documents across six domains with consistent YAML
  front matter and a fixed eight-section body template.
- 19-class safety policy with keyword classification, audit logging, and
  evaluation harness.
- Knowledge-grounded answer builder with citations, safety note, related
  skills, and related projects.
- Authorized workflow planner that only emits planning artifacts.
- 60 benchmark tasks across six categories.
- React + Vite dashboard exposing every capability through small panels.
- A comprehensive, automated pytest suite (all green).
- GitHub Actions CI with backend tests and frontend build.
- Documentation set covering architecture, threat model, knowledge model,
  retrieval model, safety policy, agent memory, skill mapping, authorized
  workflow, benchmark design, task routing, testing strategy, API surface,
  reviewer guide, portfolio summary, demo walkthrough, and diagrams.
- AI-assisted development disclosure included in README, README.zh-CN, and
  every report.
